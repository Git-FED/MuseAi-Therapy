# Escalation timeline

This timeline is a configuration proposal, not a promise that the product will contact anyone automatically.

| Time since missed/flagged event | Proposed action | Required gate |
|---|---|---|
| 7 days | Offer family/trusted-contact review | Explicit opt-in, verified contact, preview |
| 14 days | Offer non-emergency professional pathway | Membership authorization, reason, prior avenues |
| 30 days | Show emergency guidance if facts indicate immediate risk | User must contact local emergency services; no delay |
| 60 days | Re-open police consideration only as a non-emergency last resort | Human review, all prior avenues attached, no investigation recommendation |
| 90 days | Final police email option | Fresh consent, heavy disclosure, non-emergency channel, audit log |

The timers must pause when a user resolves the event, revokes consent, or enters a high-risk pathway that requires immediate professional help instead.
